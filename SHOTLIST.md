# Unity Screenshot Shot List

**Specs for every shot:** PNG, 3840x2160 (16:9), Game view or free camera, post-processing ON, no editor gizmos.
**Filename:** `NN-slug.png` exactly as listed. **HUD:** "clean" = hidden, "HUD" = visible.
**Rules:** no placeholder or untextured assets, no debug text, no console or editor UI, no pink (missing) materials. Take 2 or 3 variations of each shot.
